# Strategy Analysis Reports

This directory contains auto-generated markdown reports from the analysis engine.

## Purpose

Reports are automatically generated by the HPC pipeline and provide comprehensive analysis of each strategy's performance. These reports are designed to be:

1. **Human-readable** - Clear metrics and insights
2. **LLM-friendly** - Structured for Claude/GPT-4 analysis
3. **Version-controlled** - Track improvements over time
4. **Actionable** - Identify specific weaknesses and opportunities

## File Naming Convention

```
{Strategy_Name}_{timestamp}.md
```

Example:
```
Conservative_Income_20241228_143052.md
Momentum_Example_20241228_143052.md
```

The timestamp corresponds to the analysis database creation time, allowing you to track reports from specific simulation runs.

## How to Generate Reports

### Automatic (via Complete Pipeline)

```bash
# Run complete pipeline - reports generated automatically
cd ~/BearishVanish
./hpc_scripts/run_complete_pipeline.sh sp500 --offline
```

Reports will be automatically:
1. Generated on HPC (headless mode)
2. Downloaded to this directory
3. Ready for review

### Manual (Headless CLI)

```bash
# Generate full reports for all strategies
cd ~/BearishVanish/visualizer
python generate_report_cli.py --output ../0_docs/reports

# Generate only improvement reports
python generate_report_cli.py --output ../0_docs/reports --type improvement

# Generate for specific strategies
python generate_report_cli.py --output ../0_docs/reports \
  --strategies "Conservative Income" "Momentum Example"

# Use specific analysis database
python generate_report_cli.py \
  --database ../analysis/analysis_dbs/analysis_20241228_123456.db \
  --output ../0_docs/reports
```

### Via Web API

```bash
# Get full report via API
curl http://localhost:8000/api/v1/reports/Conservative%20Income

# Download report file
curl http://localhost:8000/api/v1/reports/Conservative%20Income/download \
  -o report.md

# Get improvement report
curl http://localhost:8000/api/v1/reports/Conservative%20Income/improvement
```

## Workflow

### 1. Generate Reports

Run the complete pipeline to generate fresh reports:

```bash
./hpc_scripts/run_complete_pipeline.sh sp500 --offline
```

### 2. Review Reports

```bash
# List generated reports
ls -lh 0_docs/reports/

# Read a report
cat 0_docs/reports/Conservative_Income_*.md | less
```

### 3. LLM Analysis

Send reports to Claude or GPT-4 for deep analysis:

```
Here's my trading strategy analysis report:

[PASTE REPORT CONTENT]

Based on this data, please:
1. Identify the main issues limiting performance
2. Suggest 3-5 specific code improvements for the entry/exit logic
3. Propose new indicators or filters that might help
4. Recommend risk management enhancements
```

### 4. Document Findings

After LLM review, document insights:

```bash
# Create findings document
cd 0_docs/Findings/strategies/
vim 2024-12-28_strategy_improvements.md
```

### 5. Implement Improvements

Update strategy code based on insights:

```bash
cd simulator/strategies/
vim strategy_conservative_income.py
```

### 6. Re-run Pipeline

Test improvements:

```bash
./hpc_scripts/run_complete_pipeline.sh sp500 --offline
```

### 7. Compare Results

Compare old vs new reports to validate improvements.

## Report Structure

### Executive Summary
- Overall performance status (🟢 Excellent, 🟡 Good, 🟠 Fair, 🔴 Poor)
- Key metrics table (return, win rate, Sharpe, drawdown)

### Key Metrics
Broken down by category:
- Return Metrics (total return, total profit, average trade)
- Win/Loss Metrics (win rate, profit factor)
- Risk Metrics (drawdown, Sharpe, Sortino, Calmar)
- Trade Metrics (duration, expectancy)

### Performance Analysis
Interpretations of:
- Win rate quality
- Profit factor assessment
- Overall performance evaluation

### Risk Analysis
Assessment of:
- Drawdown levels
- Sharpe ratio quality
- Risk-adjusted performance

### Monthly Performance
12-month table with:
- Month
- Return %
- Number of trades
- Win rate %

### Top Performers
Top 10 stocks by return with:
- Symbol
- Total return %
- Number of trades
- Average trade return %

### Drawdown Periods
5 largest drawdowns with:
- Start/end dates
- Depth %
- Recovery status
- Days to recover

### Trade Statistics
Summary metrics:
- Total trades
- Winning/losing trade counts
- Average duration
- Expected value per trade

### Weaknesses & Opportunities
Automated detection of:
- Low win rate issues
- High drawdown problems
- Poor risk-adjusted returns
- Tight profit margins
- Limited trade samples

Each issue includes:
- Severity level (HIGH, MEDIUM, LOW)
- Detailed description
- Improvement suggestion

### LLM Review Recommendations
Structured prompts for LLM analysis:
- Signal quality review
- Entry logic optimization
- Exit strategy refinement
- Indicator suggestions
- Position sizing recommendations
- Market condition analysis
- Risk management improvements
- New strategy variations

## Troubleshooting

### No reports generated

```bash
# Check if analysis database exists
ls -lh analysis/analysis_dbs/

# Check if visualizer CLI works
cd visualizer
python generate_report_cli.py --help
```

### Missing strategies in reports

```bash
# List available strategies in database
cd visualizer
python -c "
from config import discover_analysis_databases
from database.analysis_reader import AnalysisReader
db = discover_analysis_databases()[0]
reader = AnalysisReader(str(db))
print(reader.list_strategies())
"
```

### Report generation errors

```bash
# Run with verbose output
cd visualizer
python generate_report_cli.py --output ../0_docs/reports 2>&1 | tee report_gen.log
```
